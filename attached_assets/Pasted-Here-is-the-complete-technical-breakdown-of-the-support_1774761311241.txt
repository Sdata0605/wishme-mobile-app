Layout: max-w-3xl mx-auto

Real vs AI-generated videos

Search/filter logic (client-side only):


const filteredFaqs = searchQuery
  ? faqs.filter(f => 
      f.question.toLowerCase().includes(searchQuery.toLowerCase()) || 
      f.answer.toLowerCase().includes(searchQuery.toLowerCase())
    )
  : faqs;
Empty state: "No results found. Try a different search term or contact us below."
Data source: Hardcoded array, no API call

Name + Email in grid sm:grid-cols-2

Submit button: Button size="lg" className="w-full" with Send icon

const [formData, setFormData] = useState({
  name: "",

});
Submit handler:

const handleSubmit = (e: React.FormEvent) => {

};
IMPORTANT: Currently NO backend API call. The form just shows a success toast and resets. No data is saved to any database or sent to any endpoint.
