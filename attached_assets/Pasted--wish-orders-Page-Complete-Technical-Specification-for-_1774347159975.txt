/wish-orders Page -- Complete Technical Specification for Replit Mobile App
1. Purpose
This page lets authenticated users track all their celebrity wish orders (greeting cards sent to celebrities on occasions like birthdays, anniversaries, etc.). It shows two sections: Active/Pending Orders and Completed Wishes, with actions to continue a pending wish, view/download the generated greeting card, or navigate to the conversation.

3. Data Flow

1. User opens /wish-orders
2. Auth check → redirect to /auth if not logged in
3. Fetch orders:
   SELECT *, celebrities(id, name, image_url)
   FROM wish_celebrity_orders
   WHERE user_id = {profile.id}
   ORDER BY created_at DESC

4. Client-side split:
   - Pending: payment_status = 'completed' AND status != 'sent'
   - Completed: status = 'sent'

5. User actions:
   - Pending → "Continue Wish" → navigate to /wish-confirmation/{orderId}
   - Pending → "View Card" → open generated_card_image_url in browser
   - Completed → "View Conversation" → navigate to /messages
   - Completed → "View Card" → open generated_card_image_url
   - Completed → "Download" → fetch blob → trigger file download

5. Related Edge Function: send-wish-to-celebrity
This is NOT called from this page but is part of the wish flow (called from /wish-confirmation). For completeness:


POST /functions/v1/send-wish-to-celebrity
Headers:
  Authorization: Bearer {USER_JWT}
  Content-Type: application/json
Request:


{
  "orderId": "uuid-order-id"
}
Response (success):


{
  "success": true,
  "message": "Greeting card sent successfully to celebrity",
  "conversation_id": "uuid-conversation-id"
}
What it does:

Fetches the order with celebrity/user data
Validates card is generated and not already sent
Finds or creates a conversations row between user and celebrity
Inserts the greeting card as a message in messages table
Inserts an AI-generated thank-you reply from the celebrity
Updates order: card_approved = true, status = 'sent', completed_at = now()
6. Client-Side Filtering Logic

// Pending = paid but not yet sent to celebrity
const pendingOrders = orders.filter(order => 
  order.payment_status === 'completed' && order.status !== 'sent'
);

// Completed = fully sent to celebrity
const completedOrders = orders.filter(order => 
  order.status === 'sent'
);
