Celebrity Dashboard — Complete Technical Documentation for Replit Mobile App
Route: /celebrity-dashboard
Purpose
The Celebrity Dashboard is the central hub for celebrities (creators) to manage their entire presence on the platform. It provides tools for content upload, financial management, fan communication, booking management, reviews, followers, tax reports, consent verification, and profile viewing. Only users with a linked record in the celebrities table (where profile_id matches profiles.id) can access it. Admins can also view any celebrity's dashboard via a "View As" dropdown.

Authentication & Access Control

┌─────────────────────────────────────────┐
│ User logs in via Supabase Auth          │
│ ↓                                       │
│ Check: profiles.id exists?              │
│ ↓                                       │
│ Check: celebrities.profile_id = profile.id │
│ ↓ YES → Show Celebrity Dashboard       │
│ ↓ NO  → Show "Access Restricted" card  │
│         with link to /dashboard         │
└─────────────────────────────────────────┘
