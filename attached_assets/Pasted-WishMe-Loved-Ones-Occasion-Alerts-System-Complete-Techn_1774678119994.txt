WishMe — Loved Ones & Occasion Alerts System (Complete Technical Spec for Replit Mobile App)
1. SYSTEM PURPOSE
The Loved Ones system lets users save contacts (family, friends) with their birthdays and special dates. The Occasion Alerts system automatically reminds users before those dates via Email, SMS, and WhatsApp. Together they form a "never miss a special moment" pipeline: Add Contact → Add Occasions → Get Automated Reminders → Book a Celebrity Wish.

5. AUTOMATED CRON JOB (Backend)
A PostgreSQL pg_cron job runs daily at 8:00 AM executing cron_occasion_reminders():

Logic:

Query occasion_alerts JOIN profiles WHERE notification_sent IS NOT TRUE AND alert_date is 7 days or 1 day from now
For each matching alert, call send-wishme-notification edge function via net.http_post
Payload:

{
  "event_key": "occasion_reminder",
  "recipient_type": "user",
  "recipient_id": "profile-uuid",
  "data": {
    "first_name": "Rahul",
    "occasion_name": "Mom's Birthday",
    "person_name": "Sunita Sharma",
    "days": "7"
  }
}
The send-wishme-notification function checks the Communication Hub toggles and sends via enabled channels (Email/SMS/WhatsApp).

7. BUSINESS LOGIC (Client-Side)
Birthday Countdown (getUpcomingBirthday)

function getUpcomingBirthday(dateOfBirth: string): number | null {
  const dob = new Date(dateOfBirth);
  const today = new Date();
  const birthday = new Date(today.getFullYear(), dob.getMonth(), dob.getDate());
  if (birthday < today) birthday.setFullYear(today.getFullYear() + 1);
  return Math.ceil((birthday.getTime() - today.getTime()) / (1000 * 60 * 60 * 24));
}
Alert Status Badge Logic (getAlertStatus)

function getAlertStatus(occasionDate: string, alertDaysBefore: number) {
  const daysUntil = getDaysUntil(occasionDate);
  if (daysUntil < 0)  return { label: "Past", variant: "secondary" };
  if (daysUntil === 0) return { label: "Today!", variant: "destructive" };
  if (daysUntil <= alertDaysBefore) return { label: `${daysUntil} days`, variant: "destructive" };
  if (daysUntil <= 30) return { label: `${daysUntil} days`, variant: "default" };
  return { label: format(date, 'MMM dd, yyyy'), variant: "outline" };
}

9. MOBILE APP IMPLEMENTATION NOTES
Occasions JSONB field — The occasions column on loved_ones is a JSONB array, not a separate table. Parse it as List<Map> in your mobile framework.
Toggle alerts — A simple PATCH to occasion_alerts with { alert_enabled: bool }. Optimistically update UI.
Stats cards — Computed client-side from the alerts array (upcoming count, this-week count, auto-send count). No separate API call needed.
Empty state — When zero alerts exist, show a CTA button linking to the Loved Ones screen.
Relationship dropdown values: Family, Friend, Partner, Colleague, Other.
Occasion type values: Birthday, Anniversary, Custom (stored in the JSONB occasions array on loved_ones).
Alert occasion_type values (in occasion_alerts table): birthday, anniversary, custom, celebrity_event.
