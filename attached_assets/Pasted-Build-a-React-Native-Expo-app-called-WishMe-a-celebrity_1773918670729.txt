Build a React Native Expo app called "WishMe" — a celebrity video wish platform for Indian users. 
Use Expo SDK 54, Expo Router (file-based routing), TypeScript, and design it as a complete 
UI-only app (no real backend — mock all data locally).

The app must run cleanly on Expo Go (Android/iOS) via expo.dev. Do NOT use a monorepo or pnpm 
workspace. Use a single standalone Expo project with npm.
