Page: /profile — Edit Profile
File: src/pages/Profile.tsx Purpose: Lets authenticated users view and edit their personal info, manage addresses, bank details, KYC verification, change password, and sign out. Auth: Required — redirects to loading spinner if user or profile is null. Layout: Responsive — separate mobile and desktop layouts using useIsMobile() hook.

UI Sections (Mobile Layout)
1. Profile Avatar & Completion Badge
Circular avatar with gradient ring
Camera icon overlay when editing (triggers file upload)
Completion percentage badge (calculated client-side)
Name and email display
2. Identity Details Card
First Name / Last Name — editable Input fields
Email — read-only display
Phone — editable Input with Indian phone validation (/^(\+91|91)?[6-9]\d{9}$/)
3. Referral Hub Card
Shows profile.referral_code with Copy button
Share button using navigator.share() API with profile.referral_url
Invite button (UI only)
4. Delivery Addresses (EnhancedAddressManager component)
Full CRUD for addresses with country/state/area selection
Pincode auto-fill
5. Bank Accounts (BankDetailsManager component)
Full CRUD for bank details
Set default account
6. Verification Status
Aadhaar: masked number + Verified/Pending badge
PAN: number + Verified/Pending badge
When editing: input fields for Aadhaar number, PAN number, PAN document upload
7. Account Security
New Password + Confirm Password inputs
"Update Password" button
8. Sign Out Button

Endpoint 2: Update Profile (Save Changes)
PATCH /rest/v1/profiles?user_id=eq.{auth_user_id}
Headers:
  apikey: {SUPABASE_ANON_KEY}
  Authorization: Bearer {user_jwt_token}
  Content-Type: application/json
  Prefer: return=minimal

Body:
{
  "first_name": "John",
  "last_name": "Doe",
  "phone": "+919876543210",
  "avatar_url": "https://...",
  "address": "123 Main St, Mumbai",
  "bank_account_number": "1234567890",
  "bank_name": "SBI",
  "bank_ifsc": "SBIN0001234",
  "bank_account_holder_name": "John Doe",
  "aadhaar_number": "123456789012",
  "pan_number": "ABCDE1234F",
  "profile_completion_percentage": 80
}
Validation before save: Phone number validated with regex /^(\+91|91)?[6-9]\d{9}$/ (spaces/dashes stripped first). Empty phone is allowed.

Endpoint 3: Upload Profile Photo
POST /storage/v1/object/profile-photos/{user_id}/profile_{timestamp}.{ext}
Headers:
  apikey: {SUPABASE_ANON_KEY}
  Authorization: Bearer {user_jwt_token}
  Content-Type: {file_mime_type}
  x-upsert: false
  Cache-Control: 3600

Body: Raw file bytes
Then get public URL:

GET /storage/v1/object/public/profile-photos/{user_id}/profile_{timestamp}.{ext}
Constraints: Max 5MB, must be image/* type.

Endpoint 4: Upload PAN Document
POST /storage/v1/object/verification-docs/{user_id}/pan_{timestamp}.{ext}
Headers:
  apikey: {SUPABASE_ANON_KEY}
  Authorization: Bearer {user_jwt_token}
  Content-Type: {file_mime_type}

Body: Raw file bytes
Then update profile with the public URL:

PATCH /rest/v1/profiles?user_id=eq.{auth_user_id}
Body: { "pan_document_url": "https://...public-url..." }
Constraints: Max 5MB, accepts image/* or .pdf.

Endpoint 5: Change Password
Uses Supabase Auth native endpoint:

PUT /auth/v1/user
Headers:
  apikey: {SUPABASE_ANON_KEY}
  Authorization: Bearer {user_jwt_token}
  Content-Type: application/json

Body: { "password": "newPassword123" }
Validation: Min 6 characters, new password must match confirm password.

Endpoint 6: Fetch Addresses (EnhancedAddressManager)
GET /rest/v1/addresses?user_id=eq.{profile_id}&select=*&order=is_default.desc,created_at.desc
Response:


[
  {
    "id": "uuid",
    "user_id": "profile-uuid",
    "address_line1": "123 Main St",
    "address_line2": "Apt 4B",
    "city": "Mumbai",
    "pincode": "400001",
    "address_type": "home",
    "is_default": true,
    "country_id": "uuid",
    "state_id": "uuid",
    "area_id": "uuid"
  }
]
Supporting geo endpoints:

GET /rest/v1/countries?select=id,name&order=name
GET /rest/v1/states?select=id,name,country_id&order=name
GET /rest/v1/areas?select=id,name,pincode,state_id&order=name
CRUD operations:

Add: POST /rest/v1/addresses with body including user_id
Update: PATCH /rest/v1/addresses?id=eq.{id}
Delete: DELETE /rest/v1/addresses?id=eq.{id}
Set Default: First PATCH /rest/v1/addresses?user_id=eq.{id} set all is_default=false, then PATCH /rest/v1/addresses?id=eq.{id} set is_default=true
Endpoint 7: Fetch Bank Details (BankDetailsManager)
GET /rest/v1/bank_details?user_id=eq.{profile_id}&select=*&order=is_default.desc,created_at.desc
Response:


[
  {
    "id": "uuid",
    "user_id": "profile-uuid",

    "account_holder_name": "John Doe",
    "account_number": "1234567890",
    "ifsc_code": "SBIN0001234",

CRUD: Same pattern as addresses — POST to add, PATCH to update, DELETE to remove, two-step PATCH for set-default.

Endpoint 8: Sign Out
POST /auth/v1/logout
Headers:
  apikey: {SUPABASE_ANON_KEY}
  Authorization: Bearer {user_jwt_token}
Clears local storage keys matching supabase prefix.

Profile Completion Calculation (Client-Side)

// 10 fields checked: first_name, last_name, phone, address, 
// bank_account_number, bank_name, bank_ifsc, 
// bank_account_holder_name, aadhaar_number, pan_number
const filledFields = fields.filter(f => f && f.trim() !== "").length;
const base = Math.round((filledFields / 10) * 80) + 20; // 20-100 range
let bonus = 0;
if (aadhaar_verified) bonus += 10;
if (pan_verified) bonus += 10;
const total = Math.min(base + bonus, 100);
