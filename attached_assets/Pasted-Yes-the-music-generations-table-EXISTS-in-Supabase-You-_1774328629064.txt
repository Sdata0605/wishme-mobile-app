What to insert for Music (Tab 6):
Both a wallet_transactions row AND a music_generations row. The flow is:

Deduct wallet → insert into wallet_transactions with transaction_type: 'music_generation'
Call the edge function elevenlabs-generate-music
Insert into music_generations with the result (the edge function already does this server-side, so if you're calling the edge function, it handles the insert — you only need the wallet transaction on the client side)
