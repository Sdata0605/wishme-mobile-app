File: src/components/auth/PasswordStrengthMeter.tsx

Elements:

"Generate Strong Password" ghost button with <Sparkles> icon
Password input with show/hide toggle (<Eye>/<EyeOff>) and copy button (<Copy>)
Progress bar (<Progress> component, h-2)
Strength label: "Very Weak" / "Weak" / "Fair" / "Strong" / "Very Strong"
Requirements checklist in bg-muted/50 rounded-lg p-3:
"At least 12 characters" — regex: /.{12,}/
"One uppercase letter (A-Z)" — regex: /[A-Z]/
"One lowercase letter (a-z)" — regex: /[a-z]/
"One number (0-9)" — regex: /[0-9]/
"One special character (!@#$%^&*)" — regex: /[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?]/
Each requirement shows <Check> (green) or <X> (gray)
Password valid only when score >= 5 (all requirements met)
Sign-Up Validation (before OTP)
Email validation (validateEmail):

Regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
Error: "Please enter a valid email address"
Phone validation (validatePhone):

Regex: /^(\+91|91)?[6-9]\d{9}$/ (strips spaces/dashes first)
Error: "Please enter a valid Indian phone number (10 digits starting with 6-9)"
Password validation (checkPasswordStrength):

Must pass all 5 requirements (score >= 5)
Also checks common patterns (password, qwerty, 123456, etc.) and repeated chars
Phone duplicate check API:

GET /rest/v1/profiles?select=id&or=(phone.eq.9876543210,phone.eq.+919876543210)&limit=1
Response if exists:


{ "id": "some-uuid" }
Error shown: "This phone number is already registered. Please login."
