Celebrity Dashboard — Complete Tab-by-Tab Technical Documentation for Replit Mobile App
This covers all 10 tabs of the Celebrity Dashboard (/celebrity-dashboard): their purpose, UI components, data flow, Supabase queries, and API endpoints.

Tab Navigation Structure

┌─────────────────────────────────────────────────────────┐
│ Content │ Wallet │ Messages │ Events │ Consent │         │
│ Bookings │ Reviews │ Followers │ TDS │ Profile │         │
└─────────────────────────────────────────────────────────┘
Component: <Tabs> with <TabsList> (horizontal scroll on mobile, overflow-x-auto). Each <TabsTrigger> uses flex-shrink-0 text-xs sm:text-sm.

GLOBAL: Stats Overview (Above Tabs)
Renders 5 stat cards in a grid-cols-2 md:grid-cols-5 grid before the tabs.

Supabase Query (fetchStats):


{
  "table": "bookings",
  "select": "celebrity_commission, status",
  "filter": "celebrity_id = eq.{celebrity.id}",
  "client_side_calc": {
    "totalEarnings": "SUM(celebrity_commission) WHERE status = 'completed'",
    "pendingEarnings": "SUM(celebrity_commission) WHERE status IN ('pending', 'in_progress')",
    "totalBookings": "COUNT(*)",
    "rating": "celebrity.rating (from celebrities table)",
    "reviewCount": "celebrity.review_count (from celebrities table)"
  }
}

TAB 5: Consent
Purpose: Capture live photo + video consent for legal verification before the celebrity profile goes public.

Component: <ConsentCapture celebrityId={celebrity.id} onConsentSubmitted={fetchCelebrityData} />

File: src/components/celebrity/ConsentCapture.tsx

UI Flow:

Step 1 — Photo: Opens camera via getUserMedia({ video: true }), renders in <video> element, draws frame to <canvas>, creates JPEG data URL
Step 2 — Video: Opens camera+mic via getUserMedia({ video: true, audio: true }), records using MediaRecorder (webm/mp4), user reads the consent statement aloud
Submit: Uploads both to Supabase Storage and updates celebrity record
Consent Text (displayed to read aloud):

"I, hereby give my consent to use my image, voice, and likeness for promotional purposes on this platform..."

Upload Flow:


{
  "step_1_photo": {
    "operation": "supabase.storage.from('verification-docs').upload(path, photoBlob)",
    "path_format": "{celebrityId}/consent-photo-{timestamp}.jpg",
    "content_type": "image/jpeg"
  },
  "step_2_video": {
    "operation": "supabase.storage.from('verification-docs').upload(path, videoBlob)",
    "path_format": "{celebrityId}/consent-video-{timestamp}.webm",
    "content_type": "video/webm"
  },
  "step_3_update": {
    "table": "celebrities",
    "set": {
      "consent_status": "submitted",
      "consent_photo_url": "publicUrl of photo",
      "consent_video_url": "publicUrl of video",
      "consent_given_at": "new Date().toISOString()"
    },
    "filter": "id = eq.{celebrityId}"
  }
}
Consent Status Values: pending → submitted → approved (by admin) or rejected

Post-Submit UI: Shows Badge with status + submission date. If approved, green badge. If submitted, secondary badge "Pending Review".
