Here is the complete technical documentation for the User Dashboard (/dashboard) page for the Replit mobile app team.

User Dashboard — Complete Technical Documentation
Purpose
The /dashboard is the primary landing page for authenticated regular users. It provides a financial overview of the user's wallet balance, spending history across all platform services, and a searchable transaction ledger. For users who are also celebrities, it shows a floating button to switch to the Celebrity Dashboard.

Authentication & Access Control

{
  "wrapper": "AuthenticatedLayout",
  "auth_check": "useAuth() → if !user && !loading → redirect to /auth",
  "required_role": "any authenticated user (no role restriction)",
  "layout_mobile": "Header + MobileBottomNav (no sidebar)",
  "layout_desktop": "UserSidebar (collapsed by default) + Header + Footer"
}

Summary of Supabase Queries for Mobile Integration
#	Table	Select	Filter	Order	Limit	Realtime
1	profiles	wallet_balance	id = profile.id	—	1	Yes (postgres_changes on profiles)
2	wallet_transactions	*	user_id = profile.id	created_at DESC	50	No (manual fetch)
3	celebrities	id	profile_id = profile.id	—	1	No (one-time check for switcher)
No Edge Functions Used
This page uses zero edge functions. All data comes from direct Supabase client queries. The wallet balance updates in real-time via Supabase Realtime channel subscription, not polling.
